# DeployV2Dependencies — inputs and outputs

Script: [DeployV2Dependencies.s.sol](../../script/v2/DeployV2Dependencies.s.sol).
Configuration: [DependenciesConfig.sol](../../script/v2/configs/DependenciesConfig.sol),
which inherits [SharedConfig.sol](../../script/v2/configs/SharedConfig.sol).
Shared [release and deployer](../v2-deployment-configurations.md);
execution and verification [runbook](../v2-deployment-runbook.md).

This script deploys the v2 library, oracle wrapper, accounting modules, execution
policy, and both implementations. It does not upgrade the proxies or run migration.

Deployment is complete and all seven contracts are Etherscan-verified, as confirmed
by the user. The supplied addresses and code hashes match `DependenciesConfig.sol`.

## Deployment preflight reference

- Chainlink's `PRIMARY_FEED` is deployed and set in `DependenciesConfig.sol`.
- All existing addresses and live oracle reads pass the script's checks.
- The `100` bps deviation is validated against the new primary feed.
- All seven expected addresses match the final build and nonce plan in `DependenciesConfig.sol`.
- All seven expected hashes are confirmed in `DependenciesConfig.sol`.
- The signer is funded and the nonce sequence is confirmed.
- The dry run matches all seven pinned addresses.

The five indicated addresses are populated in `UpgradeConfig.sol` for
[BuildV2UpgradeBatch](./BuildV2UpgradeBatch.md). Roles, recovery/surplus addresses,
execution vehicle, fees, and capacity settings are configured there.
